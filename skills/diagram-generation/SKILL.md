# Diagram Generation

最初に「誰が何を理解するための図か」を1行で定める。情報を3〜7要素に絞り、
関係が見える構造を選ぶ。

## 出力の選択

- 編集・再利用重視: SVG / HTML / Mermaid
- スライド挿入: SVG / PNG
- 動画素材: HTML/CSSアニメーションまたはSVGフレーム

ラベル、凡例、コントラスト、読み順を確認し、画像だけで意味を伝えない。
ブランド指定がある場合は既存のデザインスキルを併用する。
