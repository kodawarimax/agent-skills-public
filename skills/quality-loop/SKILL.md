# Quality Loop

ユーザーが「90点ループ」「採点ループ」「品質ゲート」「合格するまで改善」と指定したときに使う。通常の依頼へ勝手に適用せず、明示指定または品質保証が主目的の場合だけ発動する。

## 共通ループ

1. 成果物の目的・対象者・合格条件を3行以内で固定する。
2. 対象に合う採点プロファイルを選ぶ。
3. 初稿を作り、100点満点で採点する。根拠を各項目に1行残す。
4. 最も点数の低い項目を1〜2個だけ修正する。
5. 再採点し、90点以上かつ重大な欠陥ゼロで合格とする。
6. 2回改善しても90点未満なら、原因・不足情報・次の打ち手を報告して停止する。

## 採点プロファイル

| 対象 | 配点 |
|---|---|
| 一般成果物 | 要件適合25 / 正確性25 / 使いやすさ20 / 一貫性15 / 根拠10 / 保守性5 |
| コード | 要件適合20 / 正しさ25 / テスト20 / セキュリティ15 / 可読性10 / 差分最小化10 |
| 調査・分析 | 問いへの適合20 / 情報源25 / 推論の妥当性20 / 不確実性15 / 再現性10 / 要約10 |
| 文書・コピー | 目的適合20 / 正確性20 / 読みやすさ20 / 構成15 / 文体15 / 校正10 |
| UI・デザイン | 目的適合20 / 視認性20 / 操作性15 / 一貫性15 / アクセシビリティ15 / 実装性15 |
| データ・表計算 | 定義適合20 / 数値正確性25 / 完全性15 / 可読性15 / 再現性15 / エラー処理10 |

プロファイルにない対象は「一般成果物」を使い、配点を変更した場合は理由を明示する。

## ルール

- 採点は印象ではなく、成果物・テスト・出典・画面確認など観測可能な根拠で行う。
- 90点でも、秘密情報、権利侵害、個人情報、壊れるテスト、誤った重要情報があれば不合格。
- 外部公開、送信、デプロイ、金銭、契約、削除は採点合格だけで実行許可にならない。
- 画像・動画は専用スキルの3案比較・技術検査を優先し、本ループは総合判定に使う。

## 出力

品質ループ: <profile>
初回: <点数>/100
改善: <最低項目と修正内容>
再採点: <点数>/100
判定: PASS / NEEDS_WORK / BLOCKED
根拠: <確認したテスト・出典・画面・ファイル>
